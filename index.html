qe apt repository

deb [trusted=yes] https://kroq86.github.io/ide stable main

Or with GPG signing (after key is set up):

curl -fsSL https://kroq86.github.io/ide/pubkey.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/qe.gpg
echo "deb [signed-by=/etc/apt/keyrings/qe.gpg] https://kroq86.github.io/ide stable main" | sudo tee /etc/apt/sources.list.d/qe.list
sudo apt update
sudo apt install qe
